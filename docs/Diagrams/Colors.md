### How to use this palette

* **Light/Dark Mode**: Each color has specific light and dark mode values optimized for readability and accessibility
* **Semantic Usage**: Use colors based on their intended purpose (e.g., Error Red for error states)
* **Contrast**: All colors meet WCAG AA accessibility standards for their intended use cases
* **Consistency**: Use the same semantic color across all diagrams for consistent meaning

> **Implementation Note:** When creating diagrams, use the appropriate mode colors based on your target audience or provide both variants for maximum compatibility.
