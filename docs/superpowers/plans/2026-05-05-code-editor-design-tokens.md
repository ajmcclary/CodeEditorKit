# CodeEditorDesignTokens Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a new `CodeEditorDesignTokens` SwiftPM library target that codifies `Design/tokens.css` as a UI-agnostic Swift module (Foundation only).

**Architecture:** Pure value types and `caseless enum` namespaces in a new `Sources/CodeEditorDesignTokens/` directory. No `SwiftUI`, `AppKit`, `UIKit`, or `CoreGraphics` imports. `CodeEditorPlugin` adds it as a dependency but does not yet consume it (consumption is sub-project 3). The existing `Theme` is untouched (rewritten in sub-project 2).

**Tech Stack:** Swift 6.3, SwiftPM, Swift Testing (`@Test`, `#expect`), `swift-snapshot-testing`, `swift-custom-dump`, SwiftLint.

**Companion spec:** `docs/superpowers/specs/2026-05-05-design-system-migration-design.md`. This plan implements the "Sub-project 1" section of that spec.

## Conventions

**Test framework.** New tests use Swift Testing (`import Testing`, `@Test`, `#expect`), not XCTest. The existing test target uses XCTest in most files but has already started migrating (`CodeEditorDependencyOverrideTests.swift` uses Swift Testing). Greenfield target follows the direction the codebase is moving.

**Derived color formulas.** The CSS uses `color-mix(in oklch, accent X%, black)` for `hover`/`pressed` and `color-mix(in oklch, accent X%, transparent)` for tints. We approximate using **linear sRGB** for darker variants (multiply each channel by X/100) and **alpha** for tints. Exact computed values are given in Task 11 — do not re-derive them.

**Numeric type.** All sizes/spacings/radii are `Double`, never `CGFloat`. `CoreGraphics` is excluded from this module by design.

**File-level guidance.** One namespace per file. Public symbols get DocC-style `///` comments naming the CSS variable they correspond to (e.g. `/// Mirrors --sp-lg from tokens.css.`).

**Commits.** Frequent, scoped to one task. No `--no-verify`. If SwiftLint complains, fix and re-stage in a new commit (don't amend).

```swift
import Foundation

extension Tokens {
    /// sRGB color with alpha. UI-framework agnostic.
    ///
    /// Bridging to `SwiftUI.Color`, `NSColor`, or `UIColor` lives in
    /// `CodeEditorPlugin`/`CodeEditorUI`, not here.
    public struct Color: Hashable, Sendable, Codable {
        /// Red component, 0–255.
        public let r: UInt8
        /// Green component, 0–255.
        public let g: UInt8
        /// Blue component, 0–255.
        public let b: UInt8
        /// Alpha, 0.0–1.0.
        public let alpha: Double

        public init(r: UInt8, g: UInt8, b: UInt8, alpha: Double = 1) {
            self.r = r
            self.g = g
            self.b = b
            self.alpha = alpha
        }

        /// Build from a 24-bit RGB hex literal, e.g. `0x0A84FF`.
        public init(hex: UInt32, alpha: Double = 1) {
            self.r = UInt8((hex >> 16) & 0xFF)
            self.g = UInt8((hex >> 8) & 0xFF)
            self.b = UInt8(hex & 0xFF)
            self.alpha = alpha
        }

        /// Parse from a hex string, with or without leading `#`. Accepts
        /// 6-digit (RRGGBB) or 8-digit (RRGGBBAA) forms. Returns nil on
        /// malformed input.
        public init?(hexString: String) {
            var s = hexString
            if s.hasPrefix("#") { s.removeFirst() }
            guard s.count == 6 || s.count == 8,
                  s.allSatisfy(\.isHexDigit) else { return nil }
            guard let rgb = UInt32(s.prefix(6), radix: 16) else { return nil }
            self.r = UInt8((rgb >> 16) & 0xFF)
            self.g = UInt8((rgb >> 8) & 0xFF)
            self.b = UInt8(rgb & 0xFF)
            if s.count == 8 {
                guard let a = UInt32(s.suffix(2), radix: 16) else { return nil }
                self.alpha = Double(a) / 255.0
            } else {
                self.alpha = 1
            }
        }

        /// Serialize as `#RRGGBB` (alpha == 1) or `#RRGGBBAA` (alpha < 1).
        /// Alpha component is rounded to the nearest 0–255 byte.
        public var hexString: String {
            if alpha >= 1.0 {
                return String(format: "#%02X%02X%02X", r, g, b)
            }
            let a = UInt8((alpha * 255.0).rounded())
            return String(format: "#%02X%02X%02X%02X", r, g, b, a)
        }
    }
}
```
