# Sample App Operations

Build, test, and run the CodeEditorSample:

```bash
cd CodeEditorSample

# Build sample app
swift build

# Run sample tests (35 tests)
swift test

# Run sample app
swift run CodeEditorSample

cd ..
```

Validates the demonstration application functionality and integration.
